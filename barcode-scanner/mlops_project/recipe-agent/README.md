# Recipe Agent 

AI-агент для управления кулинарными рецептами через естественный язык. Агент понимает команды пользователя, работает с базой данных SQLite и использует DeepSeek API для обработки запросов.

## Возможности

-  Создание и управление коллекциями рецептов
-  Добавление, просмотр и редактирование рецептов
-  Добавление ингредиентов и шагов приготовления
-  Поддержка контекста (активная коллекция, активный рецепт)
-  CLI интерфейс с потоковым выводом

## Технологии

- **Python 3.11+**
- **LangGraph** — построение агента с состоянием
- **LangChain** — инструменты (tools) для LLM
- **DeepSeek API** — языковая модель
- **SQLite** — хранение данных
